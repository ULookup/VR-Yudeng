# 鱼灯制作工坊：键盘操作指南

适用于当前工程版本，更新日期：2026 年 10 月 20 日。

## 1. 启动键盘模式

程序现在默认尝试启动 VR。需要直接使用键盘时，在启动参数中加入：

```text
--desktop
```

Windows 快捷方式示例：右键快捷方式，打开“属性”，在“目标”的程序路径后加上空格和参数：

```text
"实际安装目录\实际程序名称.exe" --desktop
```

请把示例路径替换成实际程序路径。VR 设备启动失败时，程序也会自动回到键盘模拟。`--desktop` 与 `--xr` 同时存在时，优先进入键盘模拟。

操作前先点击游戏窗口，使其获得键盘焦点。在 Unity 编辑器中操作时，需要让 Game 窗口获得焦点。

## 2. 先理解两种键盘操作状态

按 **F** 在“行走”和“制作”之间切换。刚进入键盘模式时处于制作状态，默认控制左手。

- **行走状态**：移动整个人，用于在工坊和室外场景中行走。
- **制作状态**：分别移动头部、左手或右手，用于观察、拿取工具和精细制作。

两种状态下，`W/A/S/D` 的用途不同。需要制作时先按 `F` 返回制作状态。

## 3. 行走与转身

| 按键 | 作用 |
| --- | --- |
| F | 切换行走／制作 |
| W / S | 向前／向后行走 |
| A / D | 向左／向右移动 |
| ← / → | 向左／向右转身 |

使用行走状态经过门口进入庭院，再沿场景道路移动。`Q/E`、上下方向键和 `Z/C` 的精细姿态调整用于制作状态。

## 4. 选择头部或双手

| 按键 | 控制对象 |
| --- | --- |
| 主键盘 1 | 头部，用于调整观察位置和视角 |
| 主键盘 2 | 左手 |
| 主键盘 3 | 右手 |

选择另一只手不会自动松开原来那只手抓着的物品，因此可以先用一只手固定材料，再切到另一只手操作工具。

## 5. 制作状态下移动与旋转

以下按键作用于当前选择的头部或手：

| 按键 | 作用 |
| --- | --- |
| W / S | 前移／后移 |
| A / D | 左移／右移 |
| Q / E | 降低／抬高 |
| ↑ / ↓ | 向上／向下转动朝向 |
| ← / → | 向左／向右转动朝向 |
| Z / C | 沿自身前后轴向两个方向翻转 |
| 按住 Shift，再按移动或旋转键 | 精细调整，速度和步幅降为通常的 20% |

点按适合小幅调整，按住可以持续移动或转动。前后左右移动以头部的水平朝向为参考；把工具转斜后，移动方向不会随工具倾斜。

## 6. 抓取、使用工具与放手

| 按键 | 作用 |
| --- | --- |
| G | 切换当前手的握持状态：按一次握持，再按一次松开 |
| T | 切换当前手的扳机状态：按一次压下，再按一次释放 |
| 空格 | 释放当前手的握持和扳机 |
| Backspace | 释放双手的握持和扳机 |

`G` 和 `T` 都是开关式操作，**不需要一直按住键盘按键**。选择头部时不能使用握持和扳机。

拿取工具的基本步骤：

1. 按 `2` 或 `3` 选择一只手。
2. 使用移动键让手接近工具的可抓取位置。
3. 按 `G` 开启握持。
4. 移动或旋转手，把工具带到材料附近；需要对准时按住 `Shift`。
5. 根据当前工序提示使用 `T` 操作工具。完成后再次按 `T` 释放扳机。
6. 按 `G` 松开握持，或按空格同时释放当前手的握持和扳机。

## 7. 点击空间界面按钮

空间按钮通过手部射线操作：

1. 选择一只空闲手；正在抓工具时，可先按空格放手，或切换到另一只空闲手。
2. 调整手的位置和朝向，让射线指向按钮。
3. 按一次 `T` 压下扳机。
4. 再按一次 `T` 释放扳机，完成点击。

**只按一次 T 会停留在按下状态，不能完成一次正常点击。** 如果不确定扳机是否已经压下，可以先按空格，再重新对准按钮并按两次 `T`。

“开始”“下一步”“安装灯具”“点亮鱼灯”等按钮是否可用，由当前制作阶段决定。灰暗按钮表示当前不可用。操作说明中的上一页、下一页同样使用射线点击。

## 8. 暂停、恢复和重新开始

| 按键 | 作用 |
| --- | --- |
| F5 | 重新开始本轮体验，恢复材料与工具并重置制作进度 |
| F6 | 暂停／继续制作或展示 |
| F7 | 找回未安装的工具和物品，保留已完成的制作进度 |
| Home | 释放双手、恢复模拟头部与双手姿态，返回制作状态并选择左手 |
| Esc | 退出体验 |

请区分三个用途：

- **手或视角调乱了**：用 `Home` 恢复模拟姿态。它不负责找回掉落物品，也不重新开始制作。
- **工具掉落或拿不到了**：用 `F7` 找回工具。
- **需要从头重做**：用 `F5` 重新开始，本轮制作进度会被重置。

## 9. 第一次操作建议

1. 用 `--desktop` 启动，点击游戏窗口。
2. 按 `3` 选择右手，将射线对准“开始”，连续按两次 `T` 完成点击。
3. 按界面提示，依次进行扎骨架、裁剪糊纸、描线上色和装灯展示。
4. 使用 `2/3` 切换双手；靠近材料后用 `Shift` 精细调整。
5. 需要离开工作台时按 `F` 进入行走状态，回到工作台后再按 `F` 返回制作状态。

## 10. 常见操作问题

| 现象 | 处理方式 |
| --- | --- |
| 按键没有反应 | 点击游戏窗口获得焦点；确认已进入键盘模拟模式，并检查是否暂停 |
| 想移动手，却让整个人走了 | 当前处于行走状态，按 F 返回制作状态 |
| 移动了错误的手或视角 | 用主键盘 1/2/3 重新选择控制对象 |
| G 没有抓到物品 | 先确保手靠近可抓取位置；按空格清除握持状态，再靠近并按 G |
| 工具一直保持使用状态 | 再按一次 T 释放扳机；或用空格释放当前手 |
| 射线对着按钮却没有点击 | 确认按钮可用、当前手未持物，并完成 T 的“按下—释放”两步 |
| 对准材料困难 | 按住 Shift，点按移动键和旋转键 |
| 下一步按钮不可用 | 查看当前工序与进度提示，先完成本阶段要求 |

本文依据当前工程输入配置整理，未新增按键或修改操作逻辑。
